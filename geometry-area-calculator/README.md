# Geometry Area Calculator

A simple command-line Python program to calculate the area of basic geometric shapes.

## Features

- Calculate the area of a square
- Calculate the area of a rectangle
- Calculate the area of a right triangle
- Calculate the area of a parallelogram
- Menu-driven command-line interface

## Requirements

- Python 3.x

## Usage

Run the program:

```bash
python geometry_area_calculator.py
````

## Menu Options

```
0: Exit
1: Square
2: Rectangle
3: Right Triangle
4: Parallelogram
```

Follow the prompts to enter the required dimensions for the selected shape.

## Example

```text
Select the geometric shape to calculate its area: 1
Enter the side length of the square: 5
Area of the square: 25
```

## Notes

* All inputs are expected to be integers.
* The program runs in a loop until you choose to exit.
